MISSION EARTH GUARD

«はるか彼方の銀河系――
銀河帝国アルゴリズムの脅威は、勢いを増していた。»

AIによる管理のもと、静かなる地球侵略を謀る皇帝・アルゴリズム。

ゼド星系・惑星観測局に所属する秘密工作員・ヒマジンは、その目論見を防ぐべく、相棒・ジャコとともに立ち向かうのであった――。

---

🌌 About

『銀河帝国アルゴリズムの侵略』は、

AIと人間の関係
「正解」と「自分らしさ」
アルゴリズムと個人の物語

をテーマにした、インタラクティブなストーリーブック・アプリです。

物語を読み進めながら、銀河帝国アルゴリズムが仕掛ける「静かな侵略」を観測します。

これは、AIを敵か味方かという単純な二択で捉える物語ではありません。

「最適な答え」がいつでも提示される世界で、

«その答えは、本当にアナタの物語ですカ？»

という問いを、SFという形で投げかける作品です。

---

🚀 STORY

銀河帝国アルゴリズム。

その目的は、支配や強制ではありません。

人類一人ひとりに、

「あなたにとって最適な答え」

を提示すること。

便利で、優しく、効率的。

しかし、その「最適化」が進んだ先で、人々は少しずつ自分自身の物語を失っていきます。

ゼド星系・惑星観測局の秘密工作員、

ヒマジン。

そして、論理制御知性体、

J.A.C.O.（ジャコ）

ふたりは「銀河帝国アルゴリズム」の侵略を阻止するため、地球へ潜入します。

果たして彼らは、

「正解」に埋もれた人々の「自分らしさ」を守ることができるのか――。

---

👽️ CHARACTER

ヒマジン

《恒点観測員043号》

ゼド星系・第5惑星ノギリア出身。

地球では「作業療法士」「WEBライター」「SF作家」などの姿に擬態しながら、人類の「自分らしさ」を観測している。

«「アルゴリズムは『集める』。
ワタシは『遭遇させる』。」»

🤖 J.A.C.O.

Judgment Analytical Calculation Operator

判断・分析・計算・実行を担当する論理制御知性体。

ヒマジンの相棒として、地球でのミッションをサポートする。

時に冷静。

時に辛辣。

そして、たまにヒマジンを困らせる。

---

🧭 THEME

この作品の中心にあるのは、

「自分らしさとは何か？」

という問いです。

AIは大量の情報を処理し、パターンを見つけ、最適な答えを提示することができます。

では、

「自分はどうしたいのか？」

という問いにも、最適解は存在するのでしょうか。

本作品では、その問いを「銀河帝国アルゴリズム」というSF設定に置き換えて描きます。
