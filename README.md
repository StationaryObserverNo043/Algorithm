AIと人間、そして「自分らしさ」をテーマにした
ストーリーブック・アプリです。

AIが「あなたにとって最適な答え」を提示する世界。

便利で、効率的で、間違いがない。

## 🧭 THEME｜テーマ

### 「自分らしさ」に最適解はあるのか？

AIは、大量の情報を集め、
そこから最適と思われる答えを導き出すことができます。

では――

**「自分はどうしたいのか」**

にも、最適解は存在するのでしょうか。

この作品では、

- 正解とは何か
- 自分らしさとは何か
- AIと人間はどう付き合うのか
- 自分の選択を、誰に委ねるのか

という問いを、SFという形で描きます。
